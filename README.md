# Pauli Brand Studio — Design Factory

This repository is the canonical Pauli design office: brand strategy, design systems, governed creative production, validation, and delivery.

## Human start
Read `CONTEXT.md`.

## Agent start
Read `AGENTS.md` first. Then follow the ICM route in `studio/_system/contracts/ICM.md`.

## Factory pipeline
`00_intake → 10_strategy → 20_design → 30_validate → 40_deliver → 50_publish`

## Quality law
Strategy before styling. Proof before claims. Builders do not approve themselves. Design work must pass the Design Guardian and the Gauntlet before delivery.

## Walk test
A cold-start agent must be able to identify the repository purpose, current stage, allowed read/write scope, required skills, required outputs, quality gates, evidence requirements, and next handoff without chat history. See `studio/_system/governance/WALK_TEST.md`.
