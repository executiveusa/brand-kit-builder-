# MORPHO — CONSTRAINTS

## Protegido

- Evidencia antes de afirmación.
- URLs de fuente originales.
- Arquitectura tenant-safe / RLS.
- Español primero, inglés segundo.
- Navegación entendible en menos de ~2 segundos.
- Accesibilidad y móvil como requisitos.
- Academy puede conservar identidad propia si queda claramente separada del producto Hospitality.
- Backend y modelo de datos no se rediseñan por estética.

## Prohibido

- copiar estética de otros proyectos del portafolio;
- “vibe green”;
- hojas como lenguaje visual principal;
- gradientes azul/morado heredados;
- glassmorphism;
- glow;
- mariposas flotantes decorativas;
- Inter/Geist/Space Grotesk/Manrope por defecto;
- giant SaaS metrics sin contexto;
- bento genérico;
- demasiadas pills;
- mapas decorativos que aparenten datos reales;
- iconografía pseudo-indígena inventada;
- apropiación de motivos culturales o artesanales;
- claims de sostenibilidad sin evidencia;
- “IA” como argumento principal de marca;
- turismo mexicano reducido a clichés tropicales.

## Requisitos

- Logo debe sobrevivir favicon / avatar / 16px.
- Wordmark debe funcionar en español e inglés sin cambiar la marca.
- Sistema debe funcionar en modo operativo denso y landing pública.
- Tipografía debe soportar español completo.
- Máximo dos familias tipográficas.
- Licencia de fuente debe quedar documentada antes de entrega.
- Color debe cumplir WCAG AA en UI.
- Controles móviles ≥ 44 × 44px renderizados.
- Motion debe informar/orientar/confirmar, nunca decorar por default.
- Reducir movimiento debe conservar jerarquía y estado.

## Anti-referencias

- dashboard de crypto;
- startup SaaS azul;
- wellness beige genérico;
- ecolodge con “hojita + serif”;
- agencia turística tropical;
- branding de gobierno;
- lujo hotelero neutro sin datos;
- visualización de datos cyberpunk.
