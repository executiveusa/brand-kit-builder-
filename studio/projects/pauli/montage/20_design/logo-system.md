# Montage — Logo System

## Core idea
The mark is a video frame containing an **M drawn as one continuous editorial sequence**. It is intentionally reduced so the identity does not depend on literal film perforations, clapperboards, sparkles, or retro cinema cues.

The identity should feel like **editing logic made visible**.

## Master assets
- `assets/montage-mark.svg` — primary symbol; true vector geometry, no raster embed.
- `assets/montage-wordmark.svg` — typographic wordmark SVG.
- `assets/montage-lockup.svg` — horizontal brand lockup.
- `assets/montage-reverse.svg` — reverse lockup for dark footage.

## Usage
Use the mark alone for favicon, app icon, watermark, social avatar, export bug and compact mobile navigation.

Use the lockup when the brand name should be explicit: navigation, launch pages, presentations, brand book and partner placements.

## Clear space
Keep clear space around the mark equal to at least **25% of the mark width**.

## Minimum size
- Digital mark: 20 px.
- Horizontal lockup: 96 px wide.
- Video watermark: 28 px mark height at 1080p minimum.

## Color
Primary: Ink `#0A0A0A` on Paper `#F4F1EA` or White.

Reverse: White `#FFFFFF` over dark imagery with sufficient contrast.

Signal `#D7A95B` is an accent, not the default logo color.

## Do not
- add film perforations to make the mark “more video”;
- put the mark in arbitrary circles;
- add gradients, bevels, glows or shadows;
- stretch, skew or rotate the lockup;
- use the raster concept image as the production logo;
- place over chaotic footage without a contrast field.

## Motion
1. Frame appears.
2. M path draws or snaps into place.
3. Wordmark resolves.
4. Hold.

Target: 600–900 ms. With reduced motion, show the final lockup immediately.
