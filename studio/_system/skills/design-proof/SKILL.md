# Design Proof Skill

Purpose: verify that release claims are true before delivery.

## Verify
- required files exist and render
- approved copy is preserved
- links and interaction paths work
- mobile and responsive behavior are checked
- accessibility checks have evidence
- fonts and images have rights/provenance
- color/type tokens match approved manifest
- exports are complete and usable
- scorecards and guardian receipts exist
- no secrets or private source material are included

## Evidence rule
No evidence means no completion claim. Record paths, screenshots/receipts, test results, hashes, URLs, or deterministic reports as appropriate.

## Output
Produce a proof receipt with PASS/FAIL, evidence pointers, unresolved risks, and rollback/recovery notes. A failed proof returns work to the owning stage; it does not patch silently.
