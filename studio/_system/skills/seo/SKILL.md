# Brand-Integrated SEO Skill

Purpose: make search discoverability, entity consistency and content architecture part of the brand system without turning the brand into keyword-stuffed marketing sludge.

This skill is evidence-aware. It may produce hypotheses from brand/audience knowledge, but it may not fabricate SEO measurements.

## Where it runs
- `10_strategy`: entity, audience intent, topic architecture and competitive/search questions.
- `20_design`: metadata/social-preview hierarchy, image/alt-text rules and template requirements.
- `40_deliver`: SEO handoff, structured-data recommendations, canonical naming/glossary and measurement spec.
- `50_publish`: verified implementation/measurement workflows when real sites/tools are available.

## Inputs
- approved or candidate brand manifest;
- audience and jobs-to-be-done;
- offer/service/product taxonomy;
- geographic/language market;
- existing website/routes/content when available;
- real search/crawl/analytics evidence when tools are available;
- claims ledger and prohibited claims.

## Required outputs
### Searchable entity
Define consistent:
- official name;
- common short name;
- category/frame;
- location/markets;
- products/services/programs;
- founder/organization relationships when public and approved;
- canonical descriptions;
- disambiguation terms.

### Search intent map
For each relevant audience/job:
- situation/problem;
- question or intent;
- useful page/content type;
- evidence needed;
- primary action;
- status: `observed`, `tool-verified`, or `hypothesis`.

### Page/topic architecture
Map topic clusters to real user decisions. Do not create pages solely to repeat keywords.

### Metadata system
Define rules/templates for:
- title;
- meta description;
- canonical URL;
- Open Graph/social title and description;
- social image safe zones;
- image alt text;
- robots/indexing decision;
- language/locale alternates where applicable.

### Structured data
Recommend schema types only when the page truth supports them. Never emit fabricated reviews, ratings, prices, events, people, organizations or offers.

### Social search / discovery
Keep brand and search consistency across:
- handles/display names;
- profile names/bios;
- location/category fields;
- captions/topics;
- video titles/descriptions;
- alt text;
- link destination and UTM conventions.

Platform-specific voice still comes from the brand voice system.

## Evidence classes
- `observed`: directly present in client/source material.
- `verified`: confirmed by a real crawler/search/analytics/SEO tool receipt.
- `hypothesis`: reasonable strategy to test, not represented as measured fact.

## Hard bans
Never invent:
- search volume;
- keyword difficulty;
- rankings/positions;
- traffic;
- backlink counts;
- competitor performance;
- Google/Search Console data;
- AI-search share of voice;
- crawl errors you did not observe.

Never:
- keyword stuff;
- make every heading a search phrase;
- replace the approved brand voice with generic SEO prose;
- create fake local pages;
- create schema for facts that do not exist;
- publish thin pages simply to increase page count.

## Quality test
SEO passes when discoverability reinforces the same clear entity, offer, audience and language the brand system already establishes.

If a search recommendation makes the brand less clear, less human or less truthful, reject it or require stronger evidence.
