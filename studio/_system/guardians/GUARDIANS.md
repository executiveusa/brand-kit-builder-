# GUARDIANS — Executable Taste & Release Law
## Taste is encoded as checks, not vibes. Guardians are independent of creators. No exceptions.

A guardian failure blocks the G4 gate. Guardians never fix; they only judge and write failure notes that get injected into the retry context packet.

---

## 1. Anti-Slop Pack (release blockers — any one fails = fail)

Deterministic where possible:
- [ ] No generic gradients (unless manifest documents a brand reason)
- [ ] No default card shadows
- [ ] No emoji as iconography (Phosphor/Radix/Tabler only)
- [ ] No lorem ipsum or placeholder copy
- [ ] No unverified metrics, testimonials, awards, or partnership claims
- [ ] No decorative AI artifacts without a business reason
- [ ] No unlicensed fonts or images (cross-check DARYA license_status + provenance.md)
- [ ] No hover-only interactions
- [ ] No body paragraph wider than 75 characters
- [ ] No more than 2 font families
- [ ] No meaningless bento grids
- [ ] No default-Shadcn aesthetic: if a surface looks like every SaaS dashboard, it fails

## 2. Krug Pack (every digital surface)

5-second purpose test · one primary action per view · clickability visually obvious (never color alone) · consistent navigation location · current location visible · headings support scanning · zero instructional text required · visual hierarchy matches information priority · recovery path always available · mobile never removes essential context

## 3. Luxury Craft Pack (the Awwwards bar)

From the Gemini/ASC3ND sessions, encoded:
- Fluid typography: `clamp()` scaling, never fixed sizes; display tracking -0.02em; small caps +0.05em
- Motion with physics: Lenis-class smooth scroll, GSAP/Framer easing, letter-stagger reveals; no fade-in-up-for-no-reason
- Restraint: 60%+ whitespace on philosophy pages; max 3 palette colors in a composition; one unexpected application per kit
- Materials: mockups with consistent lighting; print specs (paper weight, finish, process); CMYK + Pantone present
- Icon survives 16×16 favicon test in a single color, zero gradients

## 4. Rights Pack (score must be 10/10)

- Every font: license verified or free_alternative substituted; `commercial_pending` = blocked
- Every image: provenance entry with source + rights
- No client-specific expression copied from KAKU (sequence law only, never visuals)

## 5. Copy & Language Pack

- Locked copy diffed word-for-word against `protected_items`
- es-MX parity: fonts support diacritics/ñ; cultural review note present; never touristy
- Omit needless words: any sentence that can be cut without losing meaning gets flagged

## 6. Taste Memory (how the packs get smarter)

Guardians improve only through governed examples:
`accepted_examples/` + `rejected_examples/` + `rejection_reasons/` in this repo. Human-approved additions only. Agents never self-modify the packs.
