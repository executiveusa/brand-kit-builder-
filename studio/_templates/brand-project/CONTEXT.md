# Brand project template contract

Copy this folder to `studio/projects/<tenant>/<project-slug>/` when creating a new brand engagement.

## Required structure
```text
00_intake/
10_strategy/
20_design/
30_validate/
40_deliver/
50_publish/
_ledger/
```

## Stage contract
- `00_intake/` receives brief, source assets, provenance and protected constraints.
- `10_strategy/` produces research, positioning and the proposed/approved brand manifest.
- `20_design/` produces directions, tokens, mockups and HTML proof labs.
- `30_validate/` contains independent guardian reports, scorecard and verdict.
- `40_deliver/` contains approved brand book, asset package, social and developer handoff.
- `50_publish/` contains downstream publishing/listing payloads only after approval.
- `_ledger/` contains work orders, routes, evaluations and append-only event receipts.

Read `../../_system/contracts/ICM.md` before operating inside a copied project.
