# Shared creative intelligence context

`studio/_shared/` contains reusable creative intelligence available to every tenant. It is reference material and reusable production knowledge, not client-specific truth.

## Routes
- `brand-book/KAKU_BRAND_BOOK_TEMPLATE.md` — brand-book sequence and completeness reference.
- `design-systems/type/DARYA_FONT_REGISTRY.md` — typography catalog, pairings and licensing status.
- `publish/PAULIS_PLACE.md` — downstream listing/store boundary contract.
- `references/` — examples and external design references; references never become client truth automatically.

## Law
- Shared references inform project work but do not override an approved project manifest.
- Rights/provenance status must travel with reusable creative assets.
- Client-specific expression never moves into `_shared/` unless deliberately generalized and approved.
- KAKU governs sequence/completeness only; do not copy protected visual expression.
