# DARYA FONT REGISTRY
## Pauli Studio High-Fashion Typography System
### v1.0.0 — Luxury Brand Kit Builder

---

## OVERVIEW

The DARYA collection is a curated library of 14+ typefaces spanning neo-grotesques, display serifs, geometric sans, comic/display, and groovy/experimental styles. Each font has been analyzed for personality, use cases, multilingual support, and pairing potential. This registry serves as the canonical source for Pauli Studio brand kit generation.

**Rule: Maximum 2 font families per brand kit. Display for headlines + Sans/Serif for body.**

## STEVE KRUG TYPOGRAPHY RULES (ENFORCEMENT)

1. **Scanning First**: Headlines must be scannable in under 3 seconds
2. **One Primary Action**: One dominant font size per page section
3. **Clickability**: Links must be visually obvious (never rely on color alone)
4. **Hierarchy Match**: Visual weight must match information priority
5. **Paragraph Limits**: No paragraph over 75 characters wide
6. **Instructional Text**: Never require instructions to understand typography
7. **Familiar Conventions**: Stick to established type scale relationships

---

## OKLCH COLOR SCIENCE FOR TYPE

All brand kits use OKLCH for color precision:
- Body text: L ≥ 50% for accessibility
- Headlines: Can use L < 50% with sufficient size (≥24px)
- Accent type: Must maintain 4.5:1 contrast ratio minimum
- Display type: Can use lower contrast at sizes ≥48px

---

## SPACING & TYPE SCALE

Base: 16px (1rem)
Ratio: Major Third (1.250)

```
Display:   61.04px  (3.815rem)  — Hero headlines
H1:        48.83px  (3.052rem)  — Page titles
H2:        39.06px  (2.441rem)  — Section headers
H3:        31.25px  (1.953rem)  — Subsection headers
H4:        25.00px  (1.563rem)  — Card titles
Body:      16.00px  (1.000rem)  — Body text
Small:     12.80px  (0.800rem)  — Captions, labels
```

Line height: 1.5 for body, 1.2 for display
Letter-spacing: -0.02em for display, 0 for body, 0.05em for small caps
