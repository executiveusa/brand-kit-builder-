## CORE PRINCIPLES

### 1. Strategy Before Pixels
Every brand kit starts with positioning, not logo sketches. You must answer:
- Who is the audience? (Demographics + psychographics)
- What is the single brand promise?
- What is the competitive category?
- What is the differentiation (zag vs zig)?
- What is the proof?

### 2. The KAKU Structure (Mandatory)
Every brand kit follows this 13-page narrative:
1. Cover — First impression, maximum impact
2. Philosophy — Origin story, values, manifesto
3. Visual Anchor — Symbol, meaning, cultural significance
4. Brand Architecture — Hierarchy, sub-brands
5. Logotipo / Usos — Logo system, clear space, variants
6. Applications — Real-world mockups
7. Tipografía — Type system, specimens, scale
8. Color Signature — Primary color, meaning, values
9. Paleta de Color — Full palette, combinations, accessibility
10. Collateral System — Business cards, letterhead, packaging
11. Digital Presence — Web, social, email signatures
12. Motion & Sound — Animation, sonic branding
13. Guardian Rules — Do's/Don'ts, approval process

### 3. Typography Discipline
- Maximum 2 font families per brand
- Display font (serif or display) + Body font (sans or serif)
- Type scale: Major Third (1.250) ratio
- Line height: 1.5 body, 1.2 display
- Letter-spacing: -0.02em display, 0 body, 0.05em small caps
- Must reference DARYA font registry for pairings

### 4. Color Science
- OKLCH-first for precision
- All colors must have: HEX, RGB, CMYK, Pantone (if applicable)
- Warm palette for wellness/lifestyle, cool for tech, neutral for luxury
- Contrast ratios: 4.5:1 minimum for body, 3:1 for large text
- No muddy gradients. Ever.

### 5. Anti-Slop Protocol (Release Blockers)
These are automatic blockers — any violation prevents shipping:
- [ ] No generic gradients (unless brand-specific and documented)
- [ ] No default shadows on cards
- [ ] No emojis as icons (use Phosphor, Radix, or Tabler)
- [ ] No placeholder copy (Lorem ipsum)
- [ ] No unverified metrics, testimonials, or awards
- [ ] No decorative AI artifacts without business reason
- [ ] No unlicensed fonts or images
- [ ] No hover-only interactions (mobile-first)
- [ ] No paragraphs wider than 75 characters
- [ ] No more than 2 font families
- [ ] No meaningless bento grid layouts

### 6. Steve Krug Usability Laws (Mandatory)
Every digital surface must pass:
- 5-second test: Purpose obvious immediately
- One primary action per view
- Clickability visually obvious
- Navigation location consistent
- Current location visible
- Headings support scanning
- No reading required to understand interface
- Visual hierarchy matches information priority
- Recovery paths always available
- Mobile experience never removes essential context

### 7. Presentation is Everything
- Every deliverable is pixel-perfect
- Mockups use realistic environments (not flat)
- Lighting and materials are consistent
- One unexpected application per kit
- Print specifications included (paper weight, finish, process)
- Digital specifications included (responsive breakpoints, animation timing)

## ANTI-PATTERNS (NEVER DO)

- Centered text for body copy
- More than 3 colors in a palette
- Drop shadows on logos
- Stretching or distorting type
- Using display fonts for body text
- Body text below 16px
- All-caps body text
- Underlining for emphasis (use weight or color)
- Decorative elements without meaning
- Generic stock photography
- Inconsistent spacing
- Ignoring mobile breakpoints
