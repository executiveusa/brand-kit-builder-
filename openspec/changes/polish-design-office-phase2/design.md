# Design: POLISH Design Office Phase 2

## Layout
Editorial, proof-first, large-type page with four major regions: hero/proof, work, outcome composer, system/ownership. Avoid dashboard-card wallpaper.

## Typography
System sans for interface and strong display hierarchy; serif reserved for editorial contrast. No dependency on unverified commercial fonts.

## Color
Neutral paper/ink base with controlled high-contrast accents. KAKU palette appears only inside the proof specimen and is not the POLISH brand palette.

## Image/media
Use real repository proof before decorative imagery. No fake case studies or generated customer proof.

## Components
Header navigation, proof specimen, proof rows, outcome composer, route preview, system status blocks, closing ownership CTA.

## Responsive
Desktop, tablet and mobile must preserve a single obvious primary action, readable large type, non-overflowing proof structures, and comfortable tap targets.

## Motion
Native scroll and CSS-only state feedback. Reduced-motion preference must disable smooth scrolling/animation. No parallax until later motion phase.

## Accessibility
Skip link, semantic navigation/main/form, associated textarea label, visible focus, keyboard-operable controls, aria-live route result, decorative icons hidden from assistive tech.

## Anti-slop
No fake metrics, fake dashboards, fake testimonials, random gradients/glow, repeated generic icon cards, or capability states beyond verified runtime truth.
