# Proposal: POLISH Design Office Phase 2

## Problem
The Brand Studio has governed factory contracts and a static prototype, but not yet a deployable human-facing application shell that expresses the design-office model.

## Outcome
Create a React/Vite human front door where a user can understand the studio, inspect real proof, state an outcome, and receive a truthful local route preview without implying agent execution that does not exist yet.

## Scope
- apps/web application shell
- proof specimen inside deployable public assets
- outcome-first composer
- responsive/focus/reduced-motion source behavior
- HTML-first audit and PRD evidence
- preview/build/functional verification when tooling permits

## Out of scope
- Popebot runtime
- Supabase writes
- production deployment
- authentication
- billing
- agent job execution
- brand-truth mutations

## Protected items
- Phase 1 ICM architecture and canonical factory contracts
- truth labels separating prototype behavior from runtime behavior
- no fake proof, metrics, testimonials, partnerships, or backend states
- KAKU used for sequence/proof reference, not copied as POLISH identity
