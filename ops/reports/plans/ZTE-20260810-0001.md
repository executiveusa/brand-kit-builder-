## Architecture decision for this slice
Do **not** make Supabase the canonical owner of brand intelligence. ICM files + versioned manifests remain canonical and portable. Supabase is proposed for authenticated cloud state, tenancy, approvals, job/session indexes, sync metadata, and optional cloud mirrors. This preserves USB/local operation and avoids a cloud dependency for reasoning.
