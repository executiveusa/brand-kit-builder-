# ZTE-20260813-0001 — Phase 4 Universal Agent Doors

## Objective
Make REST, MCP, CLI, folder-drop, Popebot and local callers compile into the same normalized request and receipt semantics without allowing any adapter to own brand truth or factory policy.

## Files
- `interfaces/runtime/` — dependency-free normalization library and tests.
- `interfaces/_shared/` — canonical transport-neutral request/receipt schemas.
- `interfaces/{rest,mcp,cli,folder-drop,popebot}/` — thin adapter contracts/examples.
- `.github/workflows/brand-studio-interfaces.yml` — executable equivalence gate.

## Binary validation
PASS only when:
1. all six adapter fixtures normalize to the same canonical semantic payload;
2. idempotency keys are stable for semantically identical requests;
3. transport-only metadata cannot mutate tenant/project/outcome/protected inputs;
4. invalid/missing tenant/project/outcome is rejected;
5. receipts contain transport-neutral work-order identity/status;
6. Node tests pass on CI without network/secrets.

## Rollback
Revert the Phase 4 PR. No database or deployment mutation is required for this phase.

## Risk
LOW/MEDIUM — additive interface contracts. Primary risk is contract drift or duplicated business logic; equivalence tests are the guard.
