# ZTE-20260813-0002 — Phase 5 Running Factory

## Objective
Turn the documented G0→G5 design-factory law into an executable, model-agnostic runtime.

## Scope
- durable project-stage filesystem outputs;
- append-only JSONL event ledger;
- context passed forward stage-by-stage;
- injected builder provider and separate guardian provider;
- guardian score gate at 8.5;
- failure notes injected into retries;
- max three attempts before escalation;
- content-addressed output receipts;
- G5 human hold before publish;
- optional HTTP provider adapter for Hermes/LLM/runtime services.

## Binary validation
- happy path reaches G5 `gate_pending`, never auto-publishes;
- every produced output has SHA-256 receipt;
- guardian and builder must be separate provider objects;
- failed guardian feedback appears in retry context;
- third failed attempt escalates;
- rerunning same work-order replaces deterministic stage output instead of duplicating side effects;
- ledger is chronological append-only JSONL;
- tests require no network, credentials or production mutation.

## Rollback
Revert Phase 5 PR. Runtime is local/additive; no cloud mutation required.

## Risk
MEDIUM — first executable orchestration core. It cannot be labeled a live creative provider until a real provider endpoint is configured and smoke-tested.
